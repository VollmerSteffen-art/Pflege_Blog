# Pflege Blog

A personal blog documenting my nursing apprenticeship: everyday insights, digital learning, science-based practice and encouragement for future nurses.

Statische Seite ohne Build. GitHub Pages veröffentlicht den Hauptordner direkt (Branch main, Ordner Root).

Seiten: Start, Über mich, Blog, Beitrag, Podcast, Mitmachen, Kooperation, Impressum, Datenschutz.
Stil: Arial, Grün für Überschriften, Schwarz für Text, Grau für Nebeninfos (siehe style.css, Variablen oben).
